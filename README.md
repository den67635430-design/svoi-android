# СВОи — Защищённый мессенджер (Android)

Android-приложение мессенджера **СВОи** — форк Element Android.

## О проекте
СВОи — защищённый российский мессенджер с E2E шифрованием, звонками и видеоконференциями.

## Сервер
- **Homeserver**: https://svo.kodkontenta.ru

## Сборка
```bash
./gradlew assembleRelease
```
